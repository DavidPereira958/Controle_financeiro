
Controle Financeiro Pessoal

Sobre o projeto
Este projeto foi desenvolvido como atividade prática da disciplina de Coding, utilizando a linguagem Python.

O aplicativo tem como objetivo ajudar no controle das finanças pessoais, permitindo registrar o dinheiro recebido e os gastos realizados.

Funcionalidades
O programa possui as seguintes opções:

Adicionar receita.
Adicionar despesa.
Consultar saldo.
Listar movimentações.
Sair do programa.
Como funciona
Ao iniciar o programa, aparece um menu com as opções disponíveis. O usuário escolhe o que deseja fazer digitando o número correspondente.

As receitas e despesas são cadastradas com uma descrição e um valor. Depois, o sistema consegue calcular o total recebido, o total gasto e mostrar o saldo atual.

O que foi utilizado
Para desenvolver o aplicativo, foram utilizados alguns conteúdos aprendidos nas aulas de Python:

Variáveis.
Listas.
Funções (def).
Condições (if, elif e else).
Repetição (while e for).
Entrada de dados (input).
Exibição de informações (print).
Retorno de valores (return).
Como executar
Ter o Python instalado no computador.
Abrir o arquivo controle_financeiro.py.
Executar o programa pelo terminal.
Escolher uma das opções do menu.
